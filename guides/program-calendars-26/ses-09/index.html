Session 9: Build Next Year Before It Starts - Tuesday, 10/20/26, 7 PM CDT

Session 9, Build Next Year Before It Starts concludes the Building Strong Units Through Program Calendars webinar series.

Strong units don't merely preserve culture. They continually renew it by reconnecting each generation of leaders, families, and Scouts to Scouting's purpose.

The downloadable Cultural Renewal Assessment invites leaders to examine the unit's traditions for their alignment to Scouting's purpose.

  • Key Insight: Healthy cultures are protected by continually reconnecting traditions to purpose.
  • Focus: Preserving the experiences that develop character, leadership, belonging, service, and growth.
  • Outcome: Each generation rediscovers the purpose behind the traditions it inherits.
  • Action Step: Use the Culture Renewal Assessment to identify one tradition to preserve, one practice to strengthen, and one practice to reconsider or redesign.
